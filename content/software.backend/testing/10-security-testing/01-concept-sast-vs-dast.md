## 보안 테스팅의 두 축: 정적 분석(SAST)과 동적 분석(DAST)

보안 테스팅은 코드 내부를 현미경으로 들여다보는 **SAST**와, 완성된 시스템을 외부에서 타격해보는 **DAST**라는 두 가지 강력한 렌즈를 사용합니다.

### 1. SAST (Static Application Security Testing)

- **정의**: 소스 코드를 실행하지 않고 분석하여 보안 결함을 찾습니다.
- **가치**: 개발 초기 단계에서 즉각적인 피드백을 주며, 하드코딩된 비밀번호나 취약한 암호화 알고리즘을 찾아냅니다.

### 2. DAST (Dynamic Application Security Testing)

- **정의**: 실행 중인 애플리케이션에 악의적인 요청을 보내 보안 허점을 찾습니다.
- **가치**: 코드만으로는 알 수 없는 실제 실행 환경(Runtime) 및 인프라 설정의 허점을 찾아냅니다.
