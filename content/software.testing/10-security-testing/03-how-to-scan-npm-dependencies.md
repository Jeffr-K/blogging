## NPM 의존성 보안: 공급망 공격(Supply Chain Attack) 방어 전략

우리가 가져다 쓰는 오픈소스 라이브러리에 구멍이 있다면 시스템은 뚫립니다. `npm audit`과 `Snyk`을 활용하여 의존성 내의 취약점을 자동으로 스캔하십시오. 배포 전 반드시 보안 게이트(Security Gate)를 통과하게 만들어 공급망 공격으로부터 시스템을 보호하십시오.
