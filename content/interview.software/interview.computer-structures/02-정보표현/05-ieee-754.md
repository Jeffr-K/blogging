## IEEE 754 부동소수점 표준

1985년에 제정된 IEEE 754는 컴퓨터에서 실수를 표현하는 사실상의 표준입니다. C의 `float`(32비트)과 `double`(64비트)이 모두 이 표준을 따릅니다.

---

## 1. 표현 형식

IEEE 754는 부동소수점 수를 **부호(Sign)**, **지수(Exponent)**, **가수(Mantissa/Fraction)** 세 부분으로 나눕니다.

### 32비트 단정밀도 (float)

```
비트 31  |  비트 30~23  |  비트 22~0
  부호(1)  |  지수(8비트)  |  가수(23비트)
```

### 64비트 배정밀도 (double)

```
비트 63  |  비트 62~52  |  비트 51~0
  부호(1)  |  지수(11비트) |  가수(52비트)
```

---

## 2. 값 계산 공식

```
값 = (-1)^부호 × 1.가수 × 2^(지수-편향값)

편향값 (Bias):
  float:  127  (= 2^(8-1) - 1)
  double: 1023 (= 2^(11-1) - 1)
```

**"1.가수"**: 정규화된 형태에서 정수부는 항상 1이므로 저장하지 않습니다 (숨겨진 비트, Hidden Bit). 23비트로 실제로는 24비트 정밀도를 표현합니다.

---

## 3. 예제: 12.375를 float으로 변환

**1단계: 이진수로 변환**
```
12 = 1100₂
0.375 = 0.011₂  (0.375 × 2 = 0.75 → 0
                  0.75 × 2 = 1.5  → 1
                  0.5 × 2  = 1.0  → 1)
12.375 = 1100.011₂
```

**2단계: 정규화**
```
1100.011 = 1.100011 × 2³
                      ↑
                 지수 = 3
```

**3단계: 각 필드 계산**
```
부호: 0 (양수)
지수: 3 + 127 = 130 = 1000 0010₂
가수: 100011 00000000000000000 (소수점 뒤 23비트)

최종 비트 패턴:
0 10000010 10001100000000000000000
```

## 4. 특수 값

IEEE 754는 몇 가지 특수 값을 정의합니다.

### 4.1 +0과 -0

부호 비트만 다른 두 가지 0이 존재합니다. 비교 시 같다고 처리됩니다.

```c
float a = +0.0f, b = -0.0f;
printf("%d\n", a == b);  // 1 (같음)
// 그러나 1/+0 = +∞, 1/-0 = -∞
```

### 4.2 무한대 (±Infinity)

```c
float inf = 1.0f / 0.0f;   // +∞
float ninf = -1.0f / 0.0f; // -∞
printf("%f\n", inf);        // inf
printf("%d\n", isinf(inf)); // 1
```

지수: 모두 1. 가수: 모두 0.

### 4.3 NaN (Not a Number)

수학적으로 정의되지 않는 연산의 결과.

```c
float nan_val = 0.0f / 0.0f;      // NaN
float nan2 = sqrtf(-1.0f);         // NaN
printf("%d\n", isnan(nan_val));     // 1
printf("%d\n", nan_val == nan_val); // 0 (NaN은 자기 자신과도 다름!)
```

지수: 모두 1. 가수: 0이 아닌 값.

> **NaN 특성**: `NaN != NaN`이 항상 true. 이를 이용해 NaN 감지 가능.
> ```c
> bool is_nan(float x) { return x != x; }
> ```

### 4.4 비정규화 수 (Denormalized/Subnormal)

0에 매우 가까운 수 (아주 작은 수) 표현. 지수가 모두 0일 때.

```
값 = (-1)^부호 × 0.가수 × 2^(1-편향값)
```

최솟값에서 0까지 점진적으로 접근 가능 (Gradual Underflow).

## 5. float vs double 비교

| 특성 | float (32비트) | double (64비트) |
|------|--------------|----------------|
| 총 비트 | 32 | 64 |
| 지수 비트 | 8 | 11 |
| 가수 비트 | 23 | 52 |
| 유효 십진수 자리 | ~7자리 | ~15자리 |
| 최대값 | ~3.4 × 10³⁸ | ~1.8 × 10³⁰⁸ |
| 최소 정규화 | ~1.2 × 10⁻³⁸ | ~2.2 × 10⁻³⁰⁸ |
| 용도 | GPU, 게임, ML | 과학 계산, 재무 |

## 6. 비트 레벨로 float 해킹하기

```c
// float의 비트 패턴을 정수로 읽기
float f = 12.375f;
uint32_t bits;
memcpy(&bits, &f, 4);  // type punning 안전하게 수행
printf("0x%08X\n", bits);  // 0x41460000

// 부호 비트 추출
int sign = (bits >> 31) & 1;         // 0 (양수)
// 지수 추출
int exponent = ((bits >> 23) & 0xFF) - 127;  // 130 - 127 = 3
// 가수 추출
int mantissa = bits & 0x7FFFFF;      // 0x460000
```

## 핵심 요약

- **IEEE 754**: 부호(1) + 지수 + 가수의 세 필드로 실수 표현.
- **공식**: `(-1)^s × 1.mantissa × 2^(exp-bias)`
- **특수 값**: ±0, ±∞, NaN, 비정규화 수.
- **NaN**: 자기 자신과도 같지 않음. `x != x`로 감지 가능.
- **float vs double**: 7자리 vs 15자리 유효 십진수 정밀도.
- **숨겨진 비트(Hidden Bit)**: 정규화된 수의 1은 저장하지 않아 1비트를 절약.
