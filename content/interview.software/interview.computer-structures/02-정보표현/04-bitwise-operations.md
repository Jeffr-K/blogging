## 비트 연산

비트 연산은 정수의 개별 비트를 직접 조작하는 연산입니다. CPU가 직접 지원하는 가장 빠른 연산 중 하나이며, 플래그 관리, 암호화, 그래픽, 네트워크 프로토콜 등 다양한 분야에서 활용됩니다.

---

## 1. 기본 비트 연산

### 1.1 AND (`&`)

두 비트가 모두 1일 때만 1.

```
  0101 1100
& 0011 1001
-----------
  0001 1000
```

**용도**: 특정 비트를 0으로 만들기 (마스킹), 특정 비트 값 확인.

### 1.2 OR (`|`)

두 비트 중 하나라도 1이면 1.

```
  0101 1100
| 0011 1001
-----------
  0111 1101
```

**용도**: 특정 비트를 1로 세팅.

### 1.3 XOR (`^`)

두 비트가 다를 때만 1.

```
  0101 1100
^ 0011 1001
-----------
  0110 0101
```

**용도**: 비트 토글, 암호화, 두 값이 같은지 확인.

### 1.4 NOT (`~`)

모든 비트 반전.

```
~ 0101 1100
-----------
  1010 0011
```

**용도**: 마스크 생성, 2의 보수 계산.

## 2. 쉬프트 연산

### 2.1 왼쪽 쉬프트 (`<<`)

비트를 왼쪽으로 이동. 빈 자리는 0으로 채움. **2의 거듭제곱 곱셈**과 동일.

```c
int x = 1;         // 0000 0001
int y = x << 3;    // 0000 1000 = 8 (1 × 2³)
int z = 5 << 2;    // 5 × 4 = 20
```

> **주의**: 부호 있는 정수에서 1을 최상위 비트로 쉬프트하면 UB!

### 2.2 논리적 오른쪽 쉬프트 (`>>` for unsigned)

비트를 오른쪽으로 이동. 빈 자리는 0으로 채움. **2의 거듭제곱 나눗셈**.

```c
unsigned int x = 256;  // 1000 0000 ... 0000 0000
unsigned int y = x >> 3;  // 0001 0000 ... 0000 0000 = 32 (256 / 8)
```

### 2.3 산술적 오른쪽 쉬프트 (`>>` for signed)

부호 있는 정수는 최상위 비트(부호 비트)로 채움. **부호 보존**.

```c
int x = -8;        // 1111 1000 (8비트 예시)
int y = x >> 1;    // 1111 1100 = -4 (음수 나누기 2)
```

x86-64에서 `>>` 연산자는 signed에 산술 쉬프트, unsigned에 논리 쉬프트 사용.

## 3. 실전 비트 연산 패턴

### 3.1 특정 비트 확인 (Check)

```c
// n번째 비트가 1인지 확인
bool is_bit_set(int x, int n) {
    return (x >> n) & 1;
}

// 예: 0b10110100에서 5번째 비트(0-indexed from right) 확인
int x = 0b10110100;
printf("%d\n", is_bit_set(x, 5));  // 1 (5번째 비트는 1)
```

### 3.2 특정 비트 설정 (Set)

```c
// n번째 비트를 1로 만들기
int set_bit(int x, int n) {
    return x | (1 << n);
}

int x = 0b10110100;
printf("%08b\n", set_bit(x, 1));  // 0b10110110
```

### 3.3 특정 비트 클리어 (Clear)

```c
// n번째 비트를 0으로 만들기
int clear_bit(int x, int n) {
    return x & ~(1 << n);
}

int x = 0b10110100;
printf("%08b\n", clear_bit(x, 2));  // 0b10110000
```

### 3.4 특정 비트 토글 (Toggle)

```c
// n번째 비트 반전
int toggle_bit(int x, int n) {
    return x ^ (1 << n);
}
```

### 3.5 최하위 1 비트 추출

```c
// LSB(최하위 1 비트)만 남기기
int lowest_set_bit(int x) {
    return x & (-x);  // x & (~x + 1)
}

// x = 0b10110100
// -x = 0b01001100
// x & -x = 0b00000100  (4 = 2²이므로 2번째 비트)
```

### 3.6 x가 2의 거듭제곱인지 확인

```c
bool is_power_of_two(int x) {
    return x > 0 && (x & (x - 1)) == 0;
}

// 8 = 1000, 7 = 0111 → 1000 & 0111 = 0 → true
// 6 = 0110, 5 = 0101 → 0110 & 0101 = 0100 ≠ 0 → false
```

### 3.7 XOR로 두 변수 스왑 (메모리 없이)

```c
void swap(int *a, int *b) {
    *a ^= *b;  // a = a XOR b
    *b ^= *a;  // b = b XOR (a XOR b) = a
    *a ^= *b;  // a = (a XOR b) XOR a = b
}
// 주의: a와 b가 같은 변수를 가리키면 0이 됨
```

## 4. 실무 활용 예

### 4.1 플래그(Flag) 관리

```c
// 권한 플래그 정의
#define PERM_READ    (1 << 0)  // 0001
#define PERM_WRITE   (1 << 1)  // 0010
#define PERM_EXECUTE (1 << 2)  // 0100

int perms = 0;

// 읽기, 실행 권한 부여
perms |= PERM_READ | PERM_EXECUTE;  // 0101

// 쓰기 권한 확인
if (perms & PERM_WRITE) {
    printf("쓰기 권한 있음\n");
}

// 실행 권한 제거
perms &= ~PERM_EXECUTE;  // 0001
```

### 4.2 빠른 홀짝 판별

```c
bool is_even(int x) {
    return (x & 1) == 0;  // 최하위 비트가 0이면 짝수
}
// x % 2 == 0 보다 빠름 (나눗셈 불필요)
```

### 4.3 절댓값 (분기 없이)

```c
int abs_no_branch(int x) {
    int mask = x >> 31;  // 음수면 0xFFFFFFFF, 양수면 0x00000000
    return (x + mask) ^ mask;
}
```

## 핵심 요약

| 연산 | 기호 | 주요 용도 |
|------|------|----------|
| AND | `&` | 비트 마스킹, 특정 비트 확인/클리어 |
| OR | `\|` | 비트 세팅, 플래그 조합 |
| XOR | `^` | 비트 토글, 스왑, 암호화 |
| NOT | `~` | 비트 반전, 마스크 생성 |
| 왼쪽 쉬프트 | `<<` | 2ⁿ 곱셈 |
| 오른쪽 쉬프트 | `>>` | 2ⁿ 나눗셈 (산술/논리) |

- `x & (x-1)`: 최하위 1비트 제거 → 2의 거듭제곱 판별에 활용
- `x & (-x)`: 최하위 1비트만 추출 → 펜윅 트리(BIT) 등에서 활용
