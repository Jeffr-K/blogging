## 정수 표현 방식

컴퓨터는 비트로 정수를 표현합니다. 양수만 표현하는 **부호 없는 정수(Unsigned)**와 음수까지 표현하는 **2의 보수(Two's Complement)** 두 가지 방식이 있습니다.

---

## 1. 부호 없는 정수 (Unsigned Integer)

n비트 부호 없는 정수의 범위: **0 ~ 2ⁿ - 1**

```
8비트 unsigned: 0 ~ 255 (2⁸ - 1)
16비트 unsigned: 0 ~ 65535 (2¹⁶ - 1)
32비트 unsigned: 0 ~ 4,294,967,295 (약 43억)
```

변환 공식:
```
B2U(bₙ₋₁, bₙ₋₂, ..., b₁, b₀) = Σ bᵢ × 2ⁱ

예: 0b01001000 = 0×2⁷ + 1×2⁶ + 0×2⁵ + 0×2⁴ + 1×2³ + 0×2² + 0×2¹ + 0×2⁰
              = 64 + 8 = 72
```

---

## 2. 2의 보수 (Two's Complement)

현대 컴퓨터가 **부호 있는 정수를 표현하는 표준 방식**입니다. (1의 보수, 부호-크기 방식도 있지만 거의 사용하지 않습니다)

n비트 2의 보수 정수의 범위: **-2ⁿ⁻¹ ~ 2ⁿ⁻¹ - 1**

```
8비트  signed: -128 ~ 127
16비트 signed: -32768 ~ 32767
32비트 signed: -2,147,483,648 ~ 2,147,483,647 (약 ±21억)
64비트 signed: -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807
```

변환 공식 (최상위 비트만 음의 가중치):
```
B2T(bₙ₋₁, ..., b₀) = -bₙ₋₁ × 2ⁿ⁻¹ + Σᵢ₌₀ⁿ⁻² bᵢ × 2ⁱ

예: 8비트 1000 0000 = -1×2⁷ + 0 = -128  ← 최솟값
    8비트 0111 1111 = 0×2⁷ + 2⁶ + ... + 2⁰ = 127  ← 최댓값
    8비트 1111 1111 = -128 + 127 = -1
```

---

## 3. 2의 보수 계산 방법

### 방법 1: 비트 반전 후 +1

```
10 (양수)  = 0000 1010
-10을 구하려면:
1단계: 비트 반전    → 1111 0101
2단계: 1 더하기     → 1111 0110  = -10 ✓

검증: 1111 0110
     = -1×2⁷ + 1×2⁶ + 1×2⁵ + 1×2⁴ + 0×2³ + 1×2² + 1×2¹ + 0×2⁰
     = -128 + 64 + 32 + 16 + 0 + 4 + 2 + 0
     = -10 ✓
```

### 방법 2: 최하위 1 비트부터 보존

```
10  = 0000 1010
-10: 오른쪽에서 첫 번째 1(그리고 오른쪽 0들) 그대로 유지, 나머지 반전
     0000 1010
          ^ 이 1과 오른쪽 유지
     → 1111 0110
```

## 4. 부호 있는 정수와 부호 없는 정수 비교

```
8비트 비트 패턴:    부호 없는(Unsigned)    2의 보수(Signed)
0000 0000               0                     0
0111 1111             127                   127
1000 0000             128                  -128  ← 중요!
1000 0001             129                  -127
1111 1110             254                    -2
1111 1111             255                    -1
```

**핵심**: 같은 비트 패턴이지만 해석 방식에 따라 완전히 다른 값!

## 5. C언어에서의 함정

### 5.1 부호 있는 정수와 없는 정수 혼용

```c
int x = -1;
unsigned int y = 0;

// 비교할 때 x가 unsigned로 암묵적 변환됨!
if (x > y) {  // -1 → 4294967295 (0xFFFFFFFF) → TRUE!
    printf("x > y\n");  // 이 줄이 출력됨 (버그!)
}

// 올바른 방법:
if ((int)x > (int)y) {
    // ...
}
```

### 5.2 strlen()의 함정

```c
int len = strlen(s);  // strlen은 size_t (unsigned) 반환

if (len - 1 > 0) {    // 빈 문자열이면 len=0, 0-1 = 0xFFFFFFFF (unsigned)
    // 버그: 빈 문자열일 때도 이 블록 실행됨
}

// 올바른 방법:
if (len > 1) {
    // ...
}
```

## 6. 특수 값들

```c
#include <limits.h>

INT_MAX  = 2147483647  = 0x7FFFFFFF  (32비트 최댓값)
INT_MIN  = -2147483648 = 0x80000000  (32비트 최솟값)
UINT_MAX = 4294967295  = 0xFFFFFFFF  (32비트 unsigned 최댓값)

// 주의: |INT_MIN| > INT_MAX 이므로
// abs(INT_MIN) == INT_MIN 이 될 수 있음! (오버플로우)
printf("%d\n", abs(INT_MIN));  // INT_MIN 출력 (버그!)
```

## 핵심 요약

- **Unsigned**: 0 ~ 2ⁿ-1. 모든 비트가 크기에 기여.
- **2의 보수(Signed)**: -2ⁿ⁻¹ ~ 2ⁿ⁻¹-1. 최상위 비트가 음의 가중치(-2ⁿ⁻¹)를 가짐.
- **변환**: 비트 반전 후 +1.
- **C 함정**: 부호 있는 ↔ 부호 없는 혼용 시 암묵적 변환. 비교 연산에서 특히 위험.
- **|INT_MIN| > INT_MAX**: 비대칭성에 주의 (32비트 기준 최솟값은 -2147483648, 최댓값은 2147483647).
