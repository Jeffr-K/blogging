# 힙 (Heap) 자료구조 완벽 가이드

소프트웨어 엔지니어링 인터뷰에서 자주 등장하는 중요한 자료구조 중 하나인 **힙(Heap)**에 대해 알아보겠습니다. 힙은 특히 우선순위 큐(Priority Queue)를 구현하거나 최댓값/최솟값을 빠르게 찾아야 하는 문제에서 핵심적인 역할을 합니다.

## 1. 힙(Heap)이란?

힙은 **완전 이진 트리(Complete Binary Tree)** 형태의 자료구조로, 여러 개의 값들 중에서 최댓값이나 최솟값을 빠르게 찾아내도록 만들어졌습니다.

*   **완전 이진 트리:** 마지막 레벨을 제외하고 모든 레벨이 완전히 채워져 있으며, 마지막 레벨의 모든 노드는 가능한 한 가장 왼쪽에 있습니다.

힙은 혀용하는 값의 대소 관계에 따라 크게 두 가지로 나뉩니다.

## 2. 힙의 종류

### 최대 힙 (Max Heap)
*   **성질:** 부모 노드의 키 값이 자식 노드의 키 값보다 **크거나 같은** 완전 이진 트리입니다.
*   **특징:** 트리의 루트 노드가 항상 힙 내에서 **가장 큰 값**을 가집니다.

### 최소 힙 (Min Heap)
*   **성질:** 부모 노드의 키 값이 자식 노드의 키 값보다 **작거나 같은** 완전 이진 트리입니다.
*   **특징:** 트리의 루트 노드가 항상 힙 내에서 **가장 작은 값**을 가집니다.

> **주의:** 힙은 형제 노드(왼쪽 자식과 오른쪽 자식) 사이의 대소 관계는 정해져 있지 않습니다. 오직 부모와 자식 간의 관계만 유지됩니다. (반정렬 상태)

## 3. 배열을 이용한 힙의 구현

완전 이진 트리는 1차원 배열로 매우 효율적으로 표현할 수 있습니다. 배열의 인덱스를 이용하면 부모와 자식 노드의 위치를 쉽게 찾을 수 있기 때문입니다. (일반적으로 계산의 편의를 위해 인덱스 0은 사용하지 않거나, 0부터 시작하는 공식을 사용합니다.)

**인덱스가 0부터 시작하는 경우의 노드 관계:**
*   현재 노드의 인덱스: `i`
*   왼쪽 자식의 인덱스: `2i + 1`
*   오른쪽 자식의 인덱스: `2i + 2`
*   부모 노드의 인덱스: `(i - 1) / 2` (내림)

## 4. 힙의 주요 연산 및 시간 복잡도

| 연산 | 설명 | 시간 복잡도 |
| :--- | :--- | :--- |
| **삽입 (Push)** | 새로운 요소를 힙에 추가합니다. | $O(\log N)$ |
| **삭제/추출 (Pop)** | 최댓값(또는 최솟값)인 루트 노드를 제거하고 반환합니다. | $O(\log N)$ |
| **조회 (Peek)** | 루트 노드의 값을 확인합니다. (제거하지 않음) | $O(1)$ |
| **힙 생성 (Heapify)** | 정렬되지 않은 배열을 힙으로 변환합니다. | $O(N)$ |

### 삽입 (Insertion) 동작 과정 (최대 힙 기준)
1.  새로운 노드를 힙의 마지막 노드에 이어서 삽입합니다. (배열의 맨 끝에 추가)
2.  새로운 노드를 부모 노드와 비교하여, 부모보다 크다면 위치를 교환(Swap)합니다.
3.  이 과정을 힙의 성질을 만족할 때까지(또는 루트에 도달할 때까지) 위로 올라가며 반복합니다. (Up-Heap 또는 Sift-Up)

### 삭제 (Deletion) 동작 과정 (최대 힙 기준)
1.  루트 노드(최댓값)를 제거합니다.
2.  힙의 마지막 노드를 빈 루트 노드 자리로 가져옵니다.
3.  새로운 루트 노드를 자식 노드들과 비교하여, 자식 중 더 큰 노드와 위치를 교환합니다.
4.  이 과정을 힙의 성질을 만족할 때까지(또는 리프 노드에 도달할 때까지) 아래로 내려가며 반복합니다. (Down-Heap 또는 Sift-Down)

## 5. 파이썬(Python)에서의 힙 사용

파이썬에서는 `heapq` 모듈을 통해 힙 자료구조를 쉽게 사용할 수 있습니다. `heapq`는 기본적으로 **최소 힙(Min Heap)**으로 동작합니다.

```python
import heapq

# 빈 리스트를 힙으로 사용
min_heap = []

# 원소 삽입 (Push)
heapq.heappush(min_heap, 3)
heapq.heappush(min_heap, 1)
heapq.heappush(min_heap, 4)
heapq.heappush(min_heap, 2)
print(f"최소 힙: {min_heap}") # [1, 2, 4, 3]

# 원소 삭제 (Pop) - 가장 작은 원소 반환
smallest = heapq.heappop(min_heap)
print(f"추출된 최솟값: {smallest}") # 1
print(f"삭제 후 최소 힙: {min_heap}") # [2, 3, 4]

# 기존 리스트를 힙으로 변환 (Heapify)
data = [7, 5, 8, 3, 9, 6]
heapq.heapify(data)
print(f"Heapify 결과: {data}") # [3, 5, 6, 7, 9, 8]
```

**최대 힙(Max Heap) 구현 팁:**
파이썬에서 최대 힙을 사용하려면, 값을 힙에 넣을 때 부호를 반대로(`-`) 해서 넣고, 뺄 때 다시 부호를 반대로 바꾸는 방식을 흔히 사용합니다.

```python
import heapq

max_heap = []
items = [1, 3, 5, 7, 9, 2, 4, 6, 8]

# 값을 음수로 변환하여 삽입
for item in items:
    heapq.heappush(max_heap, -item)

# 추출할 때 다시 음수 기호를 붙여 원래 값으로 복원
largest = -heapq.heappop(max_heap)
print(f"최댓값: {largest}") # 9
```

## 6. 힙의 활용 사례

1.  **우선순위 큐 (Priority Queue):** 운영체제의 작업 스케줄링, 네트워크 라우팅 등 우선순위가 높은 데이터부터 처리해야 할 때 사용됩니다.
2.  **힙 정렬 (Heap Sort):** 힙 자료구조를 이용한 정렬 알고리즘으로 $O(N \log N)$의 시간 복잡도를 보장합니다.
3.  **다익스트라 알고리즘 (Dijkstra's Algorithm):** 최단 경로를 찾는 알고리즘에서 방문할 정점을 선택할 때 최소 힙이 사용되어 성능을 최적화합니다. (시간 복잡도를 $O(V^2)$에서 $O((V+E)\log V)$로 개선)
4.  **Top-K 문제:** 방대한 데이터 중 가장 크거나 작은 K개의 요소를 찾을 때 매우 효율적입니다.

## 요약

힙은 최댓값이나 최솟값을 $O(\log N)$이라는 빠른 시간에 삽입하고 추출할 수 있는 강력한 자료구조입니다. 인터뷰에서 "가장 큰 K개", "가장 작은 값부터 차례대로", "우선순위에 따라" 같은 키워드가 문제에 등장한다면 우선적으로 힙(Heap)의 사용을 고려해 보시기 바랍니다.
